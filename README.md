# 🔗 URL to QR Code Generator

A simple and efficient **URL to QR Code Generator** that converts any website URL into a scannable QR code.

## ✨ Features

* 🔗 Convert any URL into a QR code
* 📱 Easily scan generated QR codes
* ⚡ Fast and lightweight
* 🎨 Clean and simple interface
* 💾 Download the generated QR code
* ❌ Handles invalid or empty URLs

## 🛠️ Tech Stack

* **HTML**
* **CSS**
* **JavaScript**
* **QR Code API / Library**

## 🚀 How to Use

1. Enter the URL you want to convert.
2. Click the **Generate QR Code** button.
3. Your QR code will be generated instantly.
4. Scan it using any QR scanner or download it for later use.

## 💡 How It Works

The application takes the URL entered by the user and encodes it into a QR code. The generated QR code can then be scanned to open the corresponding website directly.
